Windows setup

Install the beta

Use an Unreal Engine 5.8.4 or 5.9 Preview project. The ZIP includes the companion and the original practice assets. Your Unreal installation supplies BuildPatchTool.

  1. Download and extract. Close the editor. Open the folder containing your .uproject, create Plugins if needed, and extract the entire ForageBeta folder inside it.
  2. Enable the plugin. Reopen the project, find Forage Beta in Edit → Plugins, and enable it. Allow the Python Editor Script Plugin dependency and restart when prompted.
  3. Stage the sample. Choose Window → Forage → Guided Tutorial. Approve staging the selected files. Forage checks their hashes and shows the result.
  4. Place the token. The separate add-to-project prompt copies the three verified assets to Content/ForageBetaSample. Drag SM_ForageToken from the Content Browser into the viewport. If Unreal doesn’t highlight the token, press Ctrl+Space to open the Content Drawer and browse to Content/ForageBetaSample.

Using Forage

Help and updates

Send beta feedback

How do I try my own assets?

Choose Window → Forage → Open Dashboard → Your project. Check the path to your .uproject, type part of an asset name and choose Search project. The result includes a /Game path for the Content Browser. To preview a local BuildPatch JSON manifest, open Preview a package from a local manifest and supply its path. Supply the matching dependency index to include referenced packages. Forage reports when coverage is incomplete.

How does this work with Fab?

Selective staging uses local pack data. For a new Fab download, sign into Fab in Unreal and use its normal Add to Project flow on a compatible owned pack. Fab downloads the full pack. The included Forage practice pack works offline without an Epic account.

Window → Forage is missing

Check for YourProject/Plugins/ForageBeta/ForageBeta.uplugin. A second nested ForageBeta folder prevents discovery. Enable Forage Beta and Python Editor Script Plugin, then restart Unreal. Use a clean test project if you have an older Forage plugin installed.

My sample destination already exists

Forage preserves conflicting files. Open a clean test project or back up and move the existing Content/ForageBetaSample folder before retrying. Dashboard staging writes to Saved/ForageBeta inside an open project; the native tutorial asks separately before adding files to Content.

How do I update?

Use Window → Forage → Check for Updates or the dashboard footer. You can opt into checks when Forage opens. Review the beta release notes, close Unreal, then replace the plugin folder using the new ZIP from the verified download page.
