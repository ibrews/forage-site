Unreal Engine 5.9 Preview

Hand your picks to Fab

Open a test project. Enable Fab, Unreal MCP and its toolsets. Connect your agent to both the editor and Forage. You can also run the shortlist from a terminal.

forage fab-handoff "castle with horses"

Ask the agent to find a pick in your signed-in Fab library. Choose the pack and project. Epic starts the download. Look for the imported assets in the Content Browser before placing them.

Try this with a connected agent

Use Forage’s fab-handoff tool to shortlist packs for a castle with horses. Look up the picks in my Unreal editor’s Fab library and show matching titles and sellers. Let me pick one before installing.

From the CLI, add --editor-port PORT using the port in Unreal’s Model Context Protocol preferences. Add --catalog for a public catalog lookup. Forage can run either lookup directly.

Unreal Engine 5.8 and earlier

Scout first. Add your pick in Fab.

The Forage CLI runs outside Unreal. Search the library you’ve synced, get a scene shortlist, and keep a local wishlist tagged by project. You can do all three with the editor closed.

forage query "castle"
forage describe-loadout "medieval castle"
forage wishlist ls

Check the pack’s engine compatibility in Fab. Use Add to Project in a supported editor, or select a compatible project in the Epic Games Launcher. The optional Forage editor plugin needs a matching engine and platform build.

Inside your library

Find the missing piece

Search a specific prop, or ask for a whole scene. A local cache keeps the shortlist available between editor sessions.

Keep a project wishlist

Save and tag candidates locally. Export or import lists to move them between machines.

Demo walkthrough
  1. Run forage query "horse" against the local library. It finds Horse Starter Kit from Living Systems. On 5.8 and earlier, check compatibility in Fab and add your pick manually.
  2. Ask for a castle with horses. Forage shortlists Medieval Castle from Dexsoft Games and Horse Starter Kit from Living Systems.
  3. Connect to the signed-in 5.9 Preview editor. Fab offers an asset pack for the castle. The horse kit is a complete project, so it cannot be added to this open project.
  4. Forage also selected Pro Icon Pack from Piontek. Epic handed off its UE 5.5 asset pack to the 5.9 editor. A live Asset Registry search then found 215 imported entries under /Game/ProIconPack, including its demo map.
