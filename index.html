What it does

Stop wrestling Fab. Start building.

Four things Fab should've shipped years ago.

📚

Your whole library, searchable

Hundreds of packs, one fast search. Forage's ranker is owned-aware and multi-token — it surfaces the asset Fab's own search buries three pages deep.

♾️

A wishlist with no cap the big one

Fab limits how much you can wishlist. Forage keeps an unlimited local one — save every "want", tag it by project, and the day you buy it, forage install takes over.

🤖

AI loadouts for any scene

Describe what you're making. Forage curates a tight, non-redundant set from what you own — with bloat estimates — and hands clean JSON to your AI build agent (or to you).

⚡

Zero-click install

forage install <pack> drives Unreal's Fab pane and clicks Add to Project itself. Command to cached in ~7 seconds. Walk away.
